# tOS — Decisions

状態：Draft。将来のDecision記録先を説明する。**このBootstrapでは確定Decision recordはまだ作成していない。** 指定原則は[Constitution](../CONSTITUTION.md)に、未決定は[Open Questions](../bootstrap/OPEN_QUESTIONS.md)にある。

Decisionは、何を選び、なぜ選び、何を採用しなかったかを残す。議論の要約だけでは採用状態を表せない。

記録項目の提案：識別子・題名、状態、対象と適用版、背景、選択肢、採用案、理由、制約と不利益、検証、Human Approvalの証跡、関連Specification / Outcome、置換するDecision。

状態はProposed / Accepted / Rejected / Superseded等を検討するが、具体的なschemaと採番方式は未決定。書いたAIが自分でAcceptedに昇格させない。

採用した変更は、対応するSpecificationと適用版へ反映する。SpecificationとDecisionの不整合をFresh Workerに推測させない。詳細は[Knowledge Architecture](../specifications/KNOWLEDGE_ARCHITECTURE.md)。
