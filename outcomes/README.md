# tOS — Outcomes

状態：Draft。将来のOutcome記録先を説明する。**運用・実装の実行Outcomeはまだ登録していない。** 今回の文書検査は[Self Review](../bootstrap/SELF_REVIEW.md)に記録する。

OutcomeはTaskで何を行い、どのArtifactを作り、何が検証でき、何が残ったかを記録する。成功以外に、失敗・中断・棄却した仮説も残す。

記録項目の提案：Taskと承認範囲、担当Actor、適用OS Versionと入力の版、Artifactの場所と版、実施内容、受入条件ごとの証拠、未実施検証、失敗と制約、ReviewerとHuman Approval、Finding / Triage候補、次の状態。

TaskのDone、Artifactの公開、OSのreleaseは個別の承認事項。Outcomeを保存しただけではいずれも成立しない。具体的なschema、ID、公開・非公開情報の格納方法は未決定。
